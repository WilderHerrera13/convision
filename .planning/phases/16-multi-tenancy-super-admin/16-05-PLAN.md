# 16-05 — Repository Refactor

## Goal

Refactor all repository interfaces and implementations to accept `db *gorm.DB` as the first parameter instead of storing it in the repository struct. Services accept `db *gorm.DB` and pass it through to repos. Handlers extract tenant-scoped DB from Gin context using `tenantDBFromCtx(c)`.

## Must Haves (goal-backward verification)

- All `Repository` interfaces in `internal/domain/` accept `db *gorm.DB, ...` as first param
- All repository structs in `internal/platform/storage/postgres/` no longer have a `db *gorm.DB` field
- All services in `internal/<feature>/` accept `db *gorm.DB` where they need to call repos
- Handlers in `handler.go` call `tenantDBFromCtx(c)` and pass to services
- `make build` succeeds after each wave
- `make test` succeeds after each wave

## Wave Strategy

Execute waves sequentially (2 through 6). Each wave modifies 15-25 files. After each wave, verify `make build` and `make test` pass before proceeding.
