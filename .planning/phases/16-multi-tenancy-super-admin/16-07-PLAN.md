# 16-07 — Infrastructure & Data Migration

## Goal

Configure AWS infrastructure for wildcard subdomain support (ACM certificate + CloudFront aliases). Update nginx config on EC2. Create data migration SQL to move existing `public` schema tables to `optica_main`, register the tenant, seed super admin. Create smoke test script. Redirect apex `app.opticaconvision.com` to `main.app.opticaconvision.com`.

### Task 1: Update ACM certificate for wildcard SAN

<read_first>
- terraform/main.tf (acm_certificate resource)
- terraform/variables.tf (root_domain variable)
</read_first>

<action>
In `terraform/main.tf`, update the ACM certificate resource:

```hcl
resource "aws_acm_certificate" "app" {
  domain_name               = "app.${var.root_domain}"
  subject_alternative_names = ["*.app.${var.root_domain}"]
  validation_method         = "DNS"

  lifecycle {
    create_before_destroy = true
  }
}
```

The `subject_alternative_names` adds `*.app.opticaconvision.com`. `create_before_destroy = true` ensures the old cert stays valid until the new one is deployed and attached to CloudFront.

Run:
```bash
cd terraform
terraform plan
terraform apply
```

After apply, the new certificate needs DNS validation. Check ACM console for validation CNAME records and add them to GoDaddy.
</action>

<acceptance_criteria>
- `terraform/main.tf` acm_certificate has `subject_alternative_names = ["*.app.${var.root_domain}"]`
- `lifecycle { create_before_destroy = true }` present
- `terraform plan` shows certificate replacement (not creation)
- `terraform apply` succeeds
- ACM certificate status is "Issued" with `*.app.opticaconvision.com` in SAN list
</acceptance_criteria>

### Task 4: Create data migration SQL

<read_first>
- 16-ARCHITECTURE.md §12 (migration steps)
- 16-ARCHITECTURE.md §3.1 (platform tables schema)
- convision-api-golang/db/migrations/platform/ (existing migration files for reference)
</read_first>

<action>
Create `convision-api-golang/db/migrations/platform/000021_data_migration_main_tenant.up.sql`:

```sql
DROP SCHEMA IF EXISTS optica_main CASCADE;
CREATE SCHEMA optica_main;

DO $$ DECLARE r RECORD; BEGIN
    FOR r IN SELECT tablename FROM pg_tables WHERE schemaname = 'public'
    LOOP
        EXECUTE 'ALTER TABLE public.' || quote_ident(r.tablename) || ' SET SCHEMA optica_main';
    END LOOP;
END $$;

DO $$ DECLARE r RECORD; BEGIN
    FOR r IN SELECT sequencename FROM pg_sequences WHERE schemaname = 'public'
    LOOP
        EXECUTE 'ALTER SEQUENCE public.' || quote_ident(r.sequencename) || ' SET SCHEMA optica_main';
    END LOOP;
END $$;

INSERT INTO platform.opticas (slug, name, plan, schema_name, is_active)
VALUES ('main', 'Optica Principal', 'standard', 'optica_main', true);

INSERT INTO platform.optica_features (optica_id, feature_key, is_enabled)
SELECT 1, key, true
FROM unnest(ARRAY[
    'sidebar.appointments', 'sidebar.sales', 'sidebar.purchases',
    'sidebar.inventory', 'sidebar.laboratory', 'sidebar.reports',
    'sidebar.payroll', 'sidebar.expenses', 'sidebar.clinical',
    'sidebar.catalog', 'sidebar.quotes', 'sidebar.discounts'
]) AS key;

INSERT INTO platform.super_admins (name, email, password_hash)
VALUES ('Super Admin', 'superadmin@convision.com',
  '$2a$10$92IXUNpkjO0rOQ5byMi.Ye4oKoEa3Ro9llC/.og/at2.uheWG/igi');
```

Note: The bcrypt hash in the last INSERT must be generated from the actual password. Use `htpasswd -bnBC 10 "" "password" | tr -d ':\n'` or equivalent to generate a valid bcrypt hash.

Create `000021_data_migration_main_tenant.down.sql`:

```sql
DO $$ DECLARE r RECORD; BEGIN
    FOR r IN SELECT tablename FROM pg_tables WHERE schemaname = 'optica_main'
    LOOP
        EXECUTE 'ALTER TABLE optica_main.' || quote_ident(r.tablename) || ' SET SCHEMA public';
    END LOOP;
END $$;

DO $$ DECLARE r RECORD; BEGIN
    FOR r IN SELECT sequencename FROM pg_sequences WHERE schemaname = 'optica_main'
    LOOP
        EXECUTE 'ALTER SEQUENCE optica_main.' || quote_ident(r.sequencename) || ' SET SCHEMA public';
    END LOOP;
END $$;

DELETE FROM platform.optica_features WHERE optica_id = 1;
DELETE FROM platform.super_admins WHERE email = 'superadmin@convision.com';
DELETE FROM platform.opticas WHERE slug = 'main';
DROP SCHEMA IF EXISTS optica_main CASCADE;
```
</action>

### Task 6: Create smoke test script

<read_first>
- 16-ARCHITECTURE.md (API endpoints)
- convision-api-golang/cmd/api/main.go (health check endpoint)
</read_first>

<action>
Create `convision-api-golang/scripts/smoke-test-tenant.sh`:

```bash
#!/bin/bash
set -e

BASE="https://api.opticaconvision.com"
RED='\033[0;31m'
GREEN='\033[0;32m'
NC='\033[0m'

pass() { echo -e "${GREEN}PASS${NC}: $1"; }
fail() { echo -e "${RED}FAIL${NC}: $1"; exit 1; }

echo "=== Phase 16 Multi-Tenant Smoke Tests ==="

# 1. Health check
echo -n "Health check... "
curl -sf $BASE/health > /dev/null && pass "health" || fail "health"

# 2. Tenant login on main subdomain
echo -n "Tenant login (main)... "
RESP=$(curl -s -H "Host: main.app.opticaconvision.com" \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@convision.com","password":"password"}' \
  $BASE/api/v1/auth/login)
TOKEN=$(echo $RESP | jq -r .access_token)
[ "$TOKEN" != "null" ] && [ -n "$TOKEN" ] && pass "tenant login" || fail "tenant login: $RESP"

# 3. Tenant authenticated request
echo -n "Tenant /me... "
ME=$(curl -s -H "Host: main.app.opticaconvision.com" \
  -H "Authorization: Bearer $TOKEN" \
  $BASE/api/v1/auth/me)
[ "$(echo $ME | jq -r .data.id)" != "null" ] && pass "/me" || fail "/me: $ME"

# 4. Super admin login
echo -n "Super admin login... "
SA_RESP=$(curl -s -H "Host: admin.app.opticaconvision.com" \
  -H "Content-Type: application/json" \
  -d '{"email":"superadmin@convision.com","password":"password"}' \
  $BASE/api/v1/auth/login)
SA_TOKEN=$(echo $SA_RESP | jq -r .access_token)
[ "$SA_TOKEN" != "null" ] && [ -n "$SA_TOKEN" ] && pass "super admin login" || fail "super admin login: $SA_RESP"

# 5. Super admin list opticas
echo -n "Super admin list opticas... "
OPTICAS=$(curl -s -H "Host: admin.app.opticaconvision.com" \
  -H "Authorization: Bearer $SA_TOKEN" \
  $BASE/api/v1/super-admin/opticas)
TOTAL=$(echo $OPTICAS | jq -r .total)
[ "$TOTAL" -ge 1 ] && pass "list opticas (total=$TOTAL)" || fail "list opticas: $OPTICAS"

# 6. Cross-tenant token rejection
echo -n "Cross-tenant token rejection... "
STATUS=$(curl -s -o /dev/null -w "%{http_code}" \
  -H "Host: main.app.opticaconvision.com" \
  -H "Authorization: Bearer $SA_TOKEN" \
  $BASE/api/v1/auth/me)
[ "$STATUS" = "403" ] && pass "cross-tenant rejection" || fail "cross-tenant rejection: status=$STATUS"

# 7. Apex redirect
echo -n "Apex redirect... "
REDIR=$(curl -s -o /dev/null -w "%{http_code}" https://app.opticaconvision.com)
[ "$REDIR" = "302" ] && pass "apex redirect" || fail "apex redirect: status=$REDIR"

echo ""
echo -e "${GREEN}All smoke tests passed!${NC}"
```

Make it executable: `chmod +x scripts/smoke-test-tenant.sh`
</action>

<acceptance_criteria>
- File `scripts/smoke-test-tenant.sh` exists and is executable
- Tests: health, tenant login, tenant /me, super admin login, list opticas, cross-tenant rejection, apex redirect
- All tests use `curl -sf` for status code checking
- Script exits 0 on success, 1 on first failure
</acceptance_criteria>
