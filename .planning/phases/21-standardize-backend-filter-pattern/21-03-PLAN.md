# Plan 21-03: Inventory Module Filters — all 6 inventory domains

## Objective

Replace all `map[string]any` filter patterns in the inventory module with typed Filter structs. This covers six repository interfaces and their implementations, the inventory service, and all list handlers in `handler_inventory.go`. The inventory module has no s_f/s_v coupling — all filters are already ad-hoc `c.Query()` calls, making this a clean migration.
