# Plan 21-04: Commercial Flow Filters — sale, quote, order

## Objective

Replace `map[string]any` and ad-hoc `c.Query()` patterns in the Sale, Quote, and Order modules with typed Filter structs. According to the research, these three use `saleFilterAllowlist`, `quoteFilterAllowlist`, and `orderFilterAllowlist` respectively — all straightforward exact-match maps with no special keys.
