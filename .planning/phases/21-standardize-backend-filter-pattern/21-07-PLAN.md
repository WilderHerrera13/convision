# Plan 21-07: Clinical + Supplier Domains — prescription, clinical_history, supplier

## Objective

Three domains currently call `parseApiFilters()` in their handlers. The frontend sends `s_f/s_v/s_o=or` to supplier (OR ILIKE on name/nit/email/phone), `s_f/s_v` to prescription (appointment_id), and `s_f/s_v` to clinical_history (patient_id, created_by). After migration, those `s_f/s_v` params will be silently ignored by `ShouldBindQuery` — they are unknown keys. The new typed fields (Search, PatientID, etc.) become the canonical interface.

**Frontend note:** `supplierService.ts` and `prescriptionService.ts` currently send `s_f/s_v`. After this backend migration, those frontend calls will return all records (no filter applied) until the frontend is updated to send individual named params. That frontend migration is out of scope for Phase 21.

  <action>
    Open `convision-api-golang/internal/platform/storage/postgres/supplier_repository.go`.

    Remove `var supplierFilterAllowlist = map[string]string{...}`.

    Replace the `List` method:
    ```go
    func (r *SupplierRepository) List(db *gorm.DB, f domain.SupplierFilter) ([]*domain.Supplier, int64, error) {
    	f.Clamp()
    	var suppliers []*domain.Supplier
    	var total int64

    	q := db.Model(&domain.Supplier{})

    	// f.Search replaces s_f/s_v/s_o=or — OR ILIKE across all text fields
    	if f.Search != "" {
    		like := "%" + f.Search + "%"
    		q = q.Where("name ILIKE ? OR nit ILIKE ? OR legal_name ILIKE ? OR email ILIKE ? OR phone ILIKE ?",
    			like, like, like, like, like)
    	} else {
    		// Individual named filters (used when frontend is updated)
    		if f.Name != "" {
    			q = q.Where("name ILIKE ?", "%"+f.Name+"%")
    		}
    		if f.Email != "" {
    			q = q.Where("email ILIKE ?", "%"+f.Email+"%")
    		}
    	}

    	if f.Status != "" {
    		q = q.Where("status = ?", f.Status)
    	}
    	if f.PersonType != "" {
    		q = q.Where("person_type = ?", f.PersonType)
    	}

    	if err := q.Count(&total).Error; err != nil {
    		return nil, 0, err
    	}
    	err := q.Offset(f.Offset()).Limit(f.PerPage).Order("id desc").Find(&suppliers).Error
    	return suppliers, total, err
    }
    ```

    NOTE: The exact column names (nit, legal_name, etc.) must match the actual Supplier struct tags — read the domain file before writing.
