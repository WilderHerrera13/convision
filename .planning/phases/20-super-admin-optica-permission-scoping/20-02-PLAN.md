# Plan 20-02 — Backend Permission Intersection + Filtered Permissions Endpoint

## Objective

Wire the permission intersection into the auth login/refresh flow so that JWT permissions reflect only what the optica allows. Update `ListPermissions` to filter based on the optica's ceiling. Add a new super-admin unfiltered permissions endpoint for the permission matrix UI.

## must_haves

- [ ] `loginTenantUser` and `Refresh` apply the intersection: JWT permissions = role permissions ∩ optica allowed permissions
- [ ] Super admin login (`schemaName == "platform"`) is **not** affected — no intersection applied
- [ ] Optica with no rows in `optica_allowed_permissions` → all role permissions pass through unchanged
- [ ] `GET /api/v1/permissions` returns only permissions within the optica's allowed scope (when restrictions exist)
- [ ] `GET /api/v1/super-admin/permissions` returns ALL permissions unfiltered
- [ ] Handler struct has `opticaPermRepo domain.OpticaPermissionRepository` field
- [ ] `make build` exits 0

### Task 20-02-03: Filter ListPermissions endpoint by optica scope

<read_first>
- convision-api-golang/internal/transport/http/v1/handler_role.go (find the ListPermissions handler — read it completely)
- convision-api-golang/internal/platform/auth/middleware.go (GetClaims helper — how to extract claims from gin context)
</read_first>

<action>
In `convision-api-golang/internal/transport/http/v1/handler_role.go`, modify the `ListPermissions` handler:

Current behavior: returns all permissions from the DB.

New behavior:
1. Extract claims from context: `claims, _ := jwtauth.GetClaims(c)`
2. Fetch all permissions from the DB (existing behavior).
3. If `claims.SchemaName != "platform"` (tenant user, not super admin):
   - Call `h.opticaPermRepo.HasAny(claims.OpticaID)`
   - If true: call `h.opticaPermRepo.ListByOpticaID(claims.OpticaID)`, build `allowedSet map[string]struct{}`
   - Filter the permissions slice: keep only those where `p.Key()` is in `allowedSet`
4. Return filtered (or full) list.

```go
func (h *Handler) ListPermissions(c *gin.Context) {
    db := tenantDBFromCtx(c)
    perms, err := h.permissionRepo.ListAll(db)
    if err != nil {
        respondError(c, err)
        return
    }

    claims, ok := jwtauth.GetClaims(c)
    if ok && claims.SchemaName != "platform" {
        if hasRestriction, err := h.opticaPermRepo.HasAny(claims.OpticaID); err == nil && hasRestriction {
            allowedKeys, _ := h.opticaPermRepo.ListByOpticaID(claims.OpticaID)
            allowedSet := make(map[string]struct{}, len(allowedKeys))
            for _, k := range allowedKeys {
                allowedSet[k] = struct{}{}
            }
            filtered := perms[:0]
            for _, p := range perms {
                if _, ok := allowedSet[p.Key()]; ok {
                    filtered = append(filtered, p)
                }
            }
            perms = filtered
        }
    }

    c.JSON(http.StatusOK, perms)
}
```

Note: verify the exact field name `permissionRepo` in the Handler struct before editing.
</action>

```go
// ListAllPermissionsForSuperAdmin godoc
// GET /api/v1/super-admin/permissions
// Returns the full permissions catalog (unfiltered by optica scope).
// Used by super admin to populate the optica permission matrix UI.
func (h *Handler) ListAllPermissionsForSuperAdmin(c *gin.Context) {
    if h.superAdminPermSchema == "" {
        c.JSON(http.StatusOK, []any{})
        return
    }
    // Use the global DB with search_path set to the reference tenant schema
    refDB := h.db.Exec("SET search_path TO " + h.superAdminPermSchema + ", public")
    perms, err := h.permissionRepo.ListAll(refDB)
    if err != nil {
        respondError(c, err)
        return
    }
    c.JSON(http.StatusOK, perms)
}
```
