# Plan 18-02: Build verification and smoke test for stock deduction wiring

## Objective

Confirm that all code changes from Plan 18-01 compile cleanly (`make build` exits 0) and that the stock deduction logic is correctly wired by running a sequence of targeted `grep` checks against the modified files. No new code is written in this plan; any compilation errors found here are fixed in-place and tracked as sub-tasks below.

## must_haves

- [ ] `make build` (run from `convision-api-golang/`) exits 0 with no errors
- [ ] All grep acceptance checks from Plan 18-01 pass without false negatives
- [ ] `StockMovementRepository` interface has exactly 4 methods (Create, List, ListByProduct, FindBySaleAndProduct)
- [ ] `NewService` in `sale/service.go` has exactly 10 parameters (db, saleRepo, adjRepo, productRepo, labOrderRepo, labRepo, appointmentRepo, itemRepo, movementRepo, logger)
- [ ] No `context` import is unused (i.e., `context.Background()` is referenced in the compiled code)

## Tasks

<task id="18-02-01" title="Run make build and capture output">

<read_first>
- convision-api-golang/internal/sale/service.go
- convision-api-golang/internal/domain/inventory.go
- convision-api-golang/internal/platform/storage/postgres/stock_movement_repository.go
- convision-api-golang/cmd/api/main.go
</read_first>

<action>
Run the build from the correct directory and capture the full output:

```bash
cd convision-api-golang && make build 2>&1
```

**If `make build` exits 0:** proceed to Task 18-02-02.

**If `make build` fails with compilation errors**, diagnose and fix each error in turn. Common error patterns and their fixes:

1. **`too many arguments in call to salesvc.NewService`** — Plan 18-01 Task 05 was not applied. Add `inventoryItemRepo, stockMovementRepo` before `logger` in the `salesvc.NewService(...)` call in `cmd/api/main.go`.

2. **`undefined: domain.InventoryItemRepository` or `undefined: domain.StockMovementRepository`** in `service.go` — the import for `github.com/convision/api/internal/domain` is missing or misspelled. Verify the import block starts with `"github.com/convision/api/internal/domain"`.

3. **`imported and not used: "context"`** — `context.Background()` calls are missing from `Create()` or `Cancel()`. Re-apply Plan 18-01 Task 04.

4. **`s.movementRepo.FindBySaleAndProduct undefined (type domain.StockMovementRepository has no field or method FindBySaleAndProduct)`** — Task 18-01-01 was not applied. Add the method to both the interface in `domain/inventory.go` and the postgres implementation in `stock_movement_repository.go`.

5. **`cannot use ... as type domain.InventoryItemRepository`** or similar interface satisfaction error — verify that `postgres.InventoryItemRepository` still implements all methods in `domain.InventoryItemRepository`. No methods were removed in this phase so this should not occur.

After each fix, re-run `cd convision-api-golang && make build 2>&1` until exit code is 0.
</action>

<acceptance_criteria>
- `cd convision-api-golang && make build; echo "exit:$?"` outputs `exit:0`
</acceptance_criteria>

</task>
