# Plan 18-04: Verification — build check + structural grep audit

## Objective

Confirm that all changes from Waves 1–3 are present and correct using `make build`, `npm run build`, and a set of grep structural checks. No new code is written in this plan.

## must_haves
- [ ] `make build` exits 0 (Go backend compiles with no errors)
- [ ] `npm run build` exits 0 (React frontend TypeScript compiles with no errors)
- [ ] Migration file `000038_add_default_warehouse_to_branches.up.sql` contains the correct `ALTER TABLE` statement
- [ ] `domain.Branch` has `DefaultWarehouseID` with GORM column tag
- [ ] `branch.UpdateInput` has `DefaultWarehouseID`

- [ ] `BranchFormFields.tsx` uses `inventoryService.getWarehouses` and renders a `SelectItem` for each warehouse

<action>

```bash

grep -n 'revertStock(context.Background' "$BASE/internal/sale/service.go"
```
