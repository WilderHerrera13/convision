**Step 1 — Remove `Role` field from Claims struct.** Replace:


With (remove the `Role` field, keep `UserType` if you added it in 19-02, or add it now):

```go

	UserID       uint     `json:"user_id"`
	Email        string   `json:"email"`
	UserType     string   `json:"user_type"`

	SchemaName   string   `json:"schema_name"`
```

**Step 3 — If any code reads `claims.Role`** (e.g., in middleware or handlers), update to read `claims.UserType` instead. Search for all references:

```bash

```

Update any remaining references.

**Step 4 — Remove `domain` import from jwt.go** if no longer needed (check if `domain` is used elsewhere in the file — `GenerateToken` still uses `domain.User`, so keep the import).
</action>
