# Plan 19-01: DB Migration + Seed — Rename role→role_type, create RBAC tables, insert permissions + system roles, assign existing users

## Objective

Create all PostgreSQL migrations for the RBAC system: rename `users.role` to `users.role_type`, create `roles`, `permissions`, `role_permissions`, `user_roles` tables, add `token_version` to users, seed 85+ permission keys, 4 system roles with their permission sets, and map all existing users to their matching system role. Also update Go domain models and the AutoMigrate list so local dev works without migrations.

## must_haves

- [ ] 7 SQL migration files (.up.sql + .down.sql pairs) created with idempotent DDL (`IF NOT EXISTS`, `IF EXISTS`)
- [ ] `users.role` column renamed to `users.role_type` with CHECK constraint `IN ('admin','specialist','receptionist','laboratory')` and DEFAULT 'receptionist'
- [ ] `roles` table exists with columns `id, name, description, is_default, is_system, created_by, created_at, updated_at, deleted_at` + partial unique index on `name WHERE deleted_at IS NULL` + `set_updated_at` trigger
- [ ] `permissions` table exists with columns `id, module, action, description, created_at` + unique constraint `uq_permissions_module_action UNIQUE (module, action)`
- [ ] `role_permissions` join table with composite PK `(role_id, permission_id)` and FK cascade deletes
- [ ] `user_roles` join table with composite PK `(user_id, role_id)` and FK cascade deletes + indexes on `user_id` and `role_id`
- [ ] `users.token_version` column added: `INTEGER NOT NULL DEFAULT 1`
- [ ] 85+ permission rows inserted with `ON CONFLICT (module, action) DO NOTHING`
- [ ] 4 system roles inserted: Administrador (id 1, all permissions), Especialista (id 2), Recepcionista (id 3), Laboratorio (id 4)
- [ ] All existing users get `user_roles` entry mapping to their system role by `role_type`
- [ ] `internal/domain/role.go` created with `Role`, `Permission` structs and `RoleRepository`, `PermissionRepository` interfaces
- [ ] `internal/domain/user.go` updated: `Role` field renamed to `RoleType`, `Roles []Role` association added, `TokenVersion int` added, `UserRepository` interface extended with `GetRoles`, `AssignRoles`, `IncrementTokenVersion` methods
- [ ] `internal/platform/storage/postgres/db.go` — both `Migrate()` and `MigrateTenantSchema()` include `&domain.Role{}`, `&domain.Permission{}`
- [ ] `internal/platform/storage/postgres/user_repository.go` — `userCols` uses `role_type` not `role`, `allowedUserFilters` uses `role_type`, `GetRoles`/`AssignRoles`/`IncrementTokenVersion` methods implemented

```sql
CREATE TABLE IF NOT EXISTS roles (
    id          BIGSERIAL PRIMARY KEY,
    name        VARCHAR(100) NOT NULL,
    description TEXT,
    is_default  BOOLEAN NOT NULL DEFAULT FALSE,
    is_system   BOOLEAN NOT NULL DEFAULT FALSE,
    created_by  BIGINT REFERENCES users(id),
    created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    deleted_at  TIMESTAMPTZ NULL
);

CREATE UNIQUE INDEX IF NOT EXISTS uq_roles_name ON roles (name) WHERE deleted_at IS NULL;
CREATE INDEX IF NOT EXISTS idx_roles_deleted_at ON roles (deleted_at);

-- Trigger: set_updated_at on roles
CREATE OR REPLACE FUNCTION set_updated_at()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

DO $$ BEGIN
    IF NOT EXISTS (SELECT 1 FROM pg_trigger WHERE tgname = 'trg_roles_updated_at') THEN
        CREATE TRIGGER trg_roles_updated_at
            BEFORE UPDATE ON roles
            FOR EACH ROW EXECUTE FUNCTION set_updated_at();
    END IF;
END $$;
```

Create file `convision-api-golang/db/migrations/platform/000029_create_roles_table.down.sql`:

```sql
DROP TRIGGER IF EXISTS trg_roles_updated_at ON roles;
DROP TABLE IF EXISTS roles;
```
