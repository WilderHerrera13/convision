# Plan 19-04: Frontend AuthContext — Add hasPermission, hasAnyPermission, hasAllPermissions; create usePermission hook; update User type

## Objective

Extend the frontend `AuthContext` to read the `permissions` array from the user object (populated from login response), expose `hasPermission()`, `hasAnyPermission()`, `hasAllPermissions()` methods with `useCallback` for stable references, update the `User` type to include `role_type` and `permissions`, and create a standalone `usePermission` hook. Keep deprecated `isAdmin()`, `isSpecialist()`, `isReceptionist()` for backward compat during transition. Update `App.tsx` route guards to accept `requiredPermission` alongside existing `allowedRoles`.

## must_haves

- [ ] `src/types/user.ts` — `User` interface gains `role_type?: string` and `permissions?: string[]`
- [ ] `src/contexts/AuthContext.tsx` — `User` state includes `permissions` from login/me response
- [ ] `AuthContextType` gains: `hasPermission(permission: string): boolean`, `hasAnyPermission(...permissions: string[]): boolean`, `hasAllPermissions(...permissions: string[]): boolean`
- [ ] Permission methods use `useCallback` with `[permissions]` dependency; convert `permissions` to `Set<string>` on user load for O(1) lookup
- [ ] Deprecated `isAdmin()` delegates to `hasAllPermissions([all-admin-permissions])`; `isSpecialist()` and `isReceptionist()` similarly delegate
- [ ] `isAdmin()` returns `true` for admin role_type for backward compat until all files migrated
- [ ] New file `src/hooks/usePermission.ts` with `useHasPermission`, `useHasAnyPermission`, `useHasAllPermissions` hooks that read from AuthContext
- [ ] `src/App.tsx` — `ProtectedRoute` and `BranchProtectedRoute` accept optional `requiredPermission` prop
- [ ] `src/services/auth.ts` — `LoginResponse` includes `permissions` from API response; stores them in user object
- [ ] `npm run build` exits 0

**Step 1 — Add `permissions` to the AuthContext state and login flow.**

After the `const [user, setUser] = useState<User | null>...` line, add:

```typescript
const permissionSet = useMemo<Set<string>>(() => {
  return new Set(user?.permissions ?? []);
}, [user?.permissions]);
```

**Step 2 — Add three permission methods to the `AuthContextType` interface** (inside the type/interface definition):

```typescript
hasPermission: (permission: string) => boolean;
hasAnyPermission: (...permissions: string[]) => boolean;
hasAllPermissions: (...permissions: string[]) => boolean;
```

**Step 3 — Implement the methods with useCallback** (inside the AuthProvider component, after the existing useCallback hooks for login/logout):

```typescript
const hasPermission = useCallback((permission: string): boolean => {
  return permissionSet.has(permission);
}, [permissionSet]);

const hasAnyPermission = useCallback((...permissions: string[]): boolean => {
  return permissions.some(p => permissionSet.has(p));
}, [permissionSet]);

const hasAllPermissions = useCallback((...permissions: string[]): boolean => {
  return permissions.every(p => permissionSet.has(p));
}, [permissionSet]);
```

**Step 4 — Update deprecated helpers.** Keep `isAdmin()`, `isSpecialist()`, `isReceptionist()` for backward compat. Update their implementations to check `role_type`:

```typescript
const isAdmin = useCallback((): boolean => {

const isSpecialist = useCallback((): boolean => {
  return user?.role_type === 'specialist' || user?.role === 'specialist';
}, [user]);

const isReceptionist = useCallback((): boolean => {
  return user?.role_type === 'receptionist' || user?.role === 'receptionist';
}, [user]);
```

**Step 5 — Include in the context value** (the object returned by `<AuthContext.Provider value={{...}}>`):

<task id="19-04-03" title="Create src/hooks/usePermission.ts hook">

</read_first>

<action>
Create file `convision-front/src/hooks/usePermission.ts`:

```typescript
import { useAuth } from '@/contexts/AuthContext';

/**
 * Hook: Returns true if the current user has the specified permission.
 * Usage: const canViewPatients = useHasPermission('patients:view');
 */
export function useHasPermission(permission: string): boolean {
  const { hasPermission } = useAuth();
  return hasPermission(permission);
}

/**
 * Hook: Returns true if the current user has at least one of the specified permissions.
 * Usage: const canManagePatients = useHasAnyPermission('patients:create', 'patients:edit', 'patients:delete');
 */
export function useHasAnyPermission(...permissions: string[]): boolean {
  const { hasAnyPermission } = useAuth();
  return hasAnyPermission(...permissions);
}

/**
 * Hook: Returns true if the current user has ALL of the specified permissions.
 * Usage: const isSuperAdmin = useHasAllPermissions('super_admin:access');
 */
export function useHasAllPermissions(...permissions: string[]): boolean {
  const { hasAllPermissions } = useAuth();
  return hasAllPermissions(...permissions);
}
```
</action>
