## 3. Documented exceptions to D-13 (branch_id query param)

1. **`userService.getUsers`** — sends `branch_id` (with `all`/`0` alias handling at lines 63-64) because the `ListUsers` handler (`handler.go:478`) reads `branch_id` directly from the query to route through `ListByBranch`. Per Phase 21-10 SUMMARY decision, this is a documented exception. Code comment present: `// D-13 exception: see Phase 21-10 SUMMARY`.

2. **`inventoryService.getWarehouses`** — sends `branch_id=0` as the "all branches" sentinel for super-admin warehouse views (`inventoryService.ts:215`). The middleware special-cases this value; it is not a per-row filter. Code comment present documenting the intentional exception.
