# Plan 21.1-03: Audit list-call/Filter-struct alignment and lock retirement of legacy params

## Objective

Two-part closing artifact for Phase 21.1:

1. **Retirement-grep gate (D-10):** prove no frontend file emits `s_f`/`s_v`/`s_o`, and no backend file reads them.
2. **Alignment audit (D-11):** for every frontend list/search call, cross-reference its emitted query keys against the corresponding `domain.<Entity>Filter` struct's `form:` tags. Surface every gap (FE keys with no backend tag, backend tags with no FE caller, naming drift). The output is a markdown audit report under the phase dir; this plan does NOT edit source code (drift fixes are deferred to a follow-up phase if the gap is real).

The drift row in 21.1-AUDIT.md flags this for follow-up.
