## Context

This plan fixes the three foundational layout components that block mobile responsiveness for the entire app. `ClinicalFormLayout` has hardcoded `w-[780px]` that requires ~1,200px minimum — broken on all tablets and phones. `AdminLayout` sidebar nav items use `h-9` (36px) which is below the 44px minimum touch target for mobile. The breakpoint inconsistency between `useIsMobile()` (768px) and AdminLayout sidebar collapse (1023px) must be documented. Page layouts using `p-6` on all viewports waste critical horizontal space on phones.

All UI text is in Spanish. Components stay under 200 lines.
