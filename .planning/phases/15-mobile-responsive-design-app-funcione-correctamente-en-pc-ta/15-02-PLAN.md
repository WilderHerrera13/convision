## Context

This plan is the highest-ROI change in Phase 15: converting all `grid-cols-2` (and `grid-cols-3`) without responsive breakpoints to `grid-cols-1 sm:grid-cols-2` (and `sm:grid-cols-3` respectively). This affects ~30 files across the entire app. Additionally, fixed-width sidebars (`w-[332px]`, `w-[320px]`, `w-[372px]`) need `w-full` default with `lg:` fixed width — following the pattern already used by `AppointmentFormPage.tsx` line 808.

The changes are mechanical but must be verified per file. Tasks are grouped by domain area for parallel execution.

All changes are Tailwind class string replacements. No logic changes.
