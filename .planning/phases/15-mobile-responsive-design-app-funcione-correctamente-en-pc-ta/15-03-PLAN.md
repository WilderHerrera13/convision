## Context

This plan fixes the two highest-impact receptionist pages: the appointment form and the sale creation page. The appointment form has a step indicator with hardcoded `w-[110px]` per step (4 steps = ~500px minimum, breaks on phones) and a date/time layout using `grid-cols-[1fr_1px_240px]` with no responsive fallback. The `NewAppointmentDialog` has the same date layout pattern. The NewSale page uses `flex gap-6 p-6` with no responsive direction change, causing the `w-[332px]` sidebar (already fixed in 15-02) to remain side-by-side even on narrow screens.

All UI text is in Spanish. Components stay under 200 lines.
